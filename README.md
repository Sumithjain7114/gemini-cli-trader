# Nifty 500 Signal Scanner

This project scans the Nifty 500 for bullish breakout and fast pullback candidates using Angel One SmartAPI market data. It reports **signals and paper-position exits only**. It has no order-placement code and never sends live orders.

The existing `live_trading_exec.log` contains output from the old random-price simulation. Those historical `BUY` labels are not broker executions and are not generated by the current scanner.

## Configuration

Install dependencies with `python -m pip install -r requirements.txt`. Set these environment variables locally or as GitHub Actions repository secrets:

- `ANGELONE_API_KEY`
- `ANGELONE_CLIENT_CODE`
- `ANGELONE_PIN`
- `ANGELONE_TOTP_SECRET`

Never put credentials in the JSON strategy config or commit them. In Actions, set a repository variable named `TRADER_CONFIG_JSON` to a completed copy of `strategy_config.example.json`. Fill every `null` value, map each Nifty constituent `Industry` to an Angel One NSE sector-index symbol, and list the corresponding sector-index symbols. Thresholds not specified by the strategy remain explicitly unset in the example; the scanner rejects incomplete configuration rather than inventing values. `paper_state_path` must remain `paper_state.json` for Actions persistence.

The config separates daily trend data (Minervini and 200-DMA checks) from `candle_interval` signal data. Minervini screening applies the configurable technical trend template (price/MA alignment, rising long MA, 52-week range position, and cross-sectional 1-year relative-strength percentile); no fundamental-data filters are inferred. A fast pullback requires a probe near the configured recent support followed by a close back above support and the preceding close; its initial stop is buffered below the support low.

Use the supplied `volume_pocket_pivots.pine` v6 file as a TradingView chart indicator; its volume-average, pocket-pivot, and Bull Snort checks are ported to the Python scanner, with their parameters controlled by the `volume` section. The example uses pocket pivot and Bull Snort as institutional-volume override signals for a weak sector index; change the list if a different pattern definition is intended.

The target is at least 2R (reward distance at least twice stop distance). `risk_reward_expectancy.csv` reproduces the attached table; expectancy is interpolated across its listed stop-loss rows and 30–50% batting-average columns. No extrapolation is made outside the table range. For configured rewards above 2R, the table is used as a conservative 2R baseline.

## Workflow and state

The GitHub Actions workflow reads credentials from repository secrets and strategy settings from the repository variable. It scans at a 30-minute cadence to reduce overlap with Angel One's per-symbol candle requests, emits a JSON report, and commits only `paper_state.json` so paper positions and rolling win rate survive separate workflow runs. The request pacing can be set with `ANGELONE_REQUEST_DELAY_SECONDS`; respect your account's API limits when changing it.

Run locally with `TRADER_CONFIG_JSON` set to the completed JSON object and the four Angel One environment variables configured:

```powershell
python live_cloud_trader.py
```

Run focused tests with:

```powershell
python -m unittest discover -s tests -v
```
